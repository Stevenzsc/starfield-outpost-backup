# Workshop build RE notes (Starfield 1.16.244)

Goal: restore habs the way the game builds them (snapping picks door/wall/roof variants), instead of
`PlaceAtMe`, which spawns a hab's default PackIn (sealed doors, missing walls and roof pieces).

Tools: `tools/xref` (Iced; `refs`, `calls`, `func`, `dis`, `strs`, `vtref`), `tools/id2off.sh`, `tools/off2id.sh`
(Address Library `versionlib-1-16-244-0.bin`: 0x60 header, then `uint32 offset[id]`).

## Engine (round 2)

- Engine object is a static: `Starfield.exe+0x5F5D2E0` (same pointer on every commit).
  `+0x268/+0x270` = `shared_ptr<PackinWorkshopItem>` (made by `21BE540` = make_shared), `+0x378` selected object,
  `+0x380` its recipe (type 151), `+0x608` workshop (beacon ref).
- `PackinWorkshopItem` (size 0xF0): `+0x08` array of preview refs (88 for one new hab, 218 when moving a group),
  `+0x50` parallel array, `+0x40` number of grouped items (1 new, 11 moved group), `+0xD0` hab PackIn,
  `+0xD8` runtime group PackIn (type 167, `FF...`, generated by snapping). Arrays are cleared by commit.
- Commit placed a new `OutpostGroupPackinDummy` (`0x15804`) for both a new build and a move.
- `21CBAC0(out, BSTArray<ref>*)`: make an item from existing refs (`F65FE0` adds each ref) = grab/move path.
- Engine = state machine: StateIdle, StateCreateReferences, StateSetupReferences, StateWait3D,
  StateUpdatePlacement (`21B2E20`, vfunc 0xB8), StateUpdateSnapped, StateUpdateAutoFoundation (`21B2360`),
  StateUpdateCommitSnapEdit, StatePostCommitEdit, StateDuplicateReferences, ...
- Commands are `BSService::Detail::TCmd<lambda, Event>` queued on a service (vtables at `4D492E0..4D49A50`).
  Posters: StartWorkshop `21BAA70`, NewItem `21BAB50(form*, int)`, Commit `21BB3D0()`, Cancel `21BB4A0`,
  Update `21BEBA0`, Rotate `21F4DE0(bool, float, bool)`; EditItem/CycleBehavior/RevertBehavior are built in the
  input handler `21F4F30`; StartSnapped in `21D74B0`.
- NewItem callers look the form up with `21A6B60(table +0x591EE40, id)` and pass `[+0x591EE48]->+0x28` as the int.
